10 月 18 日听 CICAI 的报告，内容从分子、医疗、图像修复延伸到端侧计算和 Agent。自己的研究方向是网安 LLM Agent，听的时候也在想其他领域的方法有哪些可以借鉴。

下面按报告顺序记下现场感受和联想；没听清的部分保留不确定性，网安例子与补充论文用于帮助理解。

## 总体感受

**记录：** Oral 报告偏应用，神经网络和统计方法讲得较少。选题可以同时衡量效果与成本，例如减少上下文示例后，效果和调用成本如何变化。多篇报告也让我想到，基准高分不一定代表真实场景表现，分数较高后尤其要看长尾任务、真实反馈和成本。

**记忆的价值：** 记忆能减少重复查询、分析和重试，也能缩短每次携带的上下文。它可以服务单个 Agent，也可以沉淀为平台或团队经验；要看任务总成本和收益，不把记忆只当成额外负担。

## 01 3D 与 TSA 做分子 AI for Science

**记录：** 用 3D 与 TSA 研究分子，具体任务没记清。TSA（张量子空间分析）尽量保留多维数据结构并提取主要模式；SVD（奇异值分解）则对矩阵提取主要方向。

**网安联想：** 可把 Agent 轨迹按“步骤 × 工具 × 行为特征”组织，观察提示注入前后的行为变化，也可分析异常如何在多 Agent 间传播。

参考：[TSA 原论文](https://papers.nips.cc/paper_files/paper/2005/hash/332647f433a1c10fa2e2ae04abfdf83e-Abstract.html)、[SVD 说明](https://numpy.org/doc/stable/reference/generated/numpy.linalg.svd.html)。

## 02 医疗任务网络与 LLM

记录称，这项工作受到武汉新冠临床启发：组合专用网络与 LLM，辅助临床判断和警报。报告强调幻觉不可接受、结果要可解释，最终处置由人负责；模型迭代有望缓解幻觉。网安 Agent 也可让检测模型发现风险、LLM 串联日志和解释依据，人做最终判断。

## 03 具身智能

哈工深、港中文的相关工作没完全听懂，先记下方向。论文写 limitation 时，可以坦承额外信息或资源让比较不完全公平，也可以说明方法只针对细分场景；主动指出最严重局限有助于读者判断。这是写作体会，不代表该报告确有这些问题。

## 04 AI + 化学与药物研发

标签稀疏时，修补和优化已有候选有时比从零生成更实用。打分可以拆成多个指标，衡量离理想目标的距离，并用实验结果继续校准，而非只拟合已有标签。

**🌰 网安多维奖励的例子：** 告警 Agent 按判断准确、证据质量、调用成本三项评分，理想值都是 1。奖励可写为 R = α × 理想点奖励 + (1−α) × 最大差距奖励。A 得分 (0.90, 0.50, 0.90)，B 得 (0.75, 0.80, 0.75)；等权时 B 约为 0.76，A 约为 0.60，B 的短板更少。越权等安全问题应设硬约束，不能由其他高分抵消。

相关思路可参照 [PRISM（2026 预印本）](https://arxiv.org/abs/2607.24353)的理想点与 Chebyshev 多维奖励，以及[多目标参考点理论](https://pure.iiasa.ac.at/id/eprint/1117/7/WP-79-066.pdf)。PRISM 做的是文生图提示词优化，并非药物研发；尚不能确认它就是报告所引用的工作。

## 05 北京体育大学：老图像修复

报告提到通道注意力，为有用特征通道加权。交叉注意力则让一组信息按需读取另一组信息，例如图像修复中结合文字指令。L2 像素误差可能把多种细节平均成模糊结果；若用 L2 平滑梯度，也可能压平真实边缘。柯西型惩罚让大梯度的惩罚增长较慢，有机会保留边缘；现场所说的具体公式尚未确认。

参考：[PASD（ECCV 2024）](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/01705.pdf)、[TransRFIR](https://arxiv.org/abs/2404.10342)、[柯西型图像复原](https://arxiv.org/abs/2005.00657)。

## 06 视觉任务与长尾问题

长尾指少数常见类别样本很多，许多稀有类别样本很少；模型容易学好常见类、漏掉稀有类。成因包括数据难收集、标注成本高，简单复制又容易过拟合。可尝试重采样、类别平衡或 focal loss、解耦分类器和 logit adjustment；网安评估应看各类召回率与宏平均 F1，不能只看总体准确率。

参考：[Class-Balanced Loss](https://openaccess.thecvf.com/content_CVPR_2019/html/Cui_Class-Balanced_Loss_Based_on_Effective_Number_of_Samples_CVPR_2019_paper.html)、[Focal Loss](https://openaccess.thecvf.com/content_iccv_2017/html/Lin_Focal_Loss_for_ICCV_2017_paper.html)、[Logit Adjustment](https://openreview.net/forum?id=37nvvqkCo5)。

## 07 下午场：端侧、边缘协同与具身智能安全

老教授的表达很松弛，手势、语调和停顿都自然，值得学习。报告谈到端侧 LLM 与边缘节点协同，也提醒具身智能的风险会落到真实物理环境。对网安 Agent，可考虑轻量模型先筛查、强模型处理复杂分析，同时约束权限并保留停止机制。

## 08 多模态大模型、动态识别与蒙特卡洛树搜索

报告介绍了多模态动态识别、修复优化与评估体系，也提到 MCTS（蒙特卡洛树搜索）。MCTS 把多步决策展开成树，反复选择、扩展、试走并回传结果，让搜索预算集中到更有希望的路线；它可以用沙箱或模拟环境评估 Agent 的候选动作，不需要改模型权重。

**🌰 用 MCTS 规划网安告警调查的例子：** 对异常登录告警，Agent 可选择查登录历史、进程树或网络连接；在日志副本中比较路线，若异常进程与可疑外联相互印证，就优先继续查这条证据链。搜索会增加调用成本，且依赖可靠评价与可恢复环境。

参考：[MCTS 综述](https://ieeexplore.ieee.org/document/6145622/)、[LATS（ICML 2024）](https://proceedings.mlr.press/v235/zhou24r.html)。

## 09 自适应动态规划

现场记下的是自适应动态规划与贝尔曼最优。贝尔曼思路很简单：动作价值要同时算眼前收益和后续收益；ADP 用数据近似价值或策略，再逐步改进。

**🌰 多 Agent 发言权分配的例子：** 网安研判中，争议若在 IP 情报，就让情报 Agent 先补证据；若在结论是否被日志支持，就让复核 Agent 发言。可按新增证据、分歧变化和调用成本调整谁先发言。这是选题联想，具体算法要看是否需要考虑多轮影响。

参考：[Sutton 与 Barto《强化学习》](https://www.incompleteideas.net/book/bookdraft2018mar21.pdf)、[Bertsekas 的 ADP 讲义](https://arxiv.org/abs/1507.01026)。

## 10 华为相关产品负责人：Agent、GRPO 与记忆

报告提到，大模型正逐渐内化早期 Agent 的任务编排和工具调用能力。GRPO 是一种强化学习方法：同一任务生成多条回答或轨迹，按组内相对奖励更新模型，不另训练价值网络；但仍需要可靠奖励和多次采样。

**🌰 用 GRPO 训练网安 Agent 的例子：** 同一沙箱告警跑四条调查轨迹，奖励为 (1, 1, 0, 0)，训练时鼓励成功且有证据的轨迹。GRPO 是训练方法；MCTS 则是在运行时搜索路线。

**记忆与长程学习：** 现场记下的 “mengen” 很可能是 MemGen；千问相关路线的论文名尚未确认。MemGen 根据推理状态触发并生成模型可用的隐空间记忆；这不同于把文字转成 embedding 后检索原文，也需要模型内部接口和训练支持。显式文本记忆更易查验，隐式记忆不保证天然省算力。

SFT 可学习经验证的任务轨迹，GRPO 可比较同题的多条执行结果。RSI（递归自我改进）与 harness（工具、上下文、记忆、调度、恢复和评估等执行系统）可以形成“执行、验证、改进、再执行”的循环；需要用真实任务效果验证改进。记忆可按 Agent、平台、团队逐层共享，目标是少重复、降总成本。生成式记忆与系统协同进化的调研已补进 Multi-Agent-Security-Analysis 开发周报，相关能力尚未实现。

参考：[DeepSeekMath / GRPO](https://arxiv.org/abs/2402.03300)、[MemGen](https://arxiv.org/abs/2509.24704)、[InfMem](https://arxiv.org/abs/2602.02704)。

## 11 潘云鹤院士：通专融合与可靠智能

我的理解是，医疗、具身智能等具体领域需要可靠智能，尤其不能接受影响决策和物理行动的高频幻觉。通专融合可把通用模型与专业知识、行业数据和实践经验结合；数据要覆盖真实场景并深入细节，也要兼顾处理深度、覆盖广度与响应速度。报告以国家人工智能规划开篇，体现了技术讨论与长期布局相结合的视角。

报告里的 proximity 让我想到 FrontPost 的“用户相对知识新颖性”：在内容可靠且与当前问题相关的前提下，找出用户可能不熟悉、又有迁移价值的跨领域信息。proximity 的具体报告出处尚未确认；[Google 推荐文档中的向量接近度](https://developers.google.com/machine-learning/recommendation/overview/candidate-generation)和 [Google Similarity Distance](https://arxiv.org/abs/cs/0412098) 是相关概念，不宜直接认定为报告所指。

**🌰 FrontPost 跨领域推荐的例子：** 关注网安 Agent 可靠性的用户，可以看到具身智能动作约束如何启发工具权限检查；系统应解释二者的联系和迁移局限，而非只推荐语义上最远的内容。可用 [MMR](https://doi.org/10.1145/290941.291025) 作为相关性与多样性重排基线，再评估用户是否觉得有启发。此构想尚未在 FrontPost 实现或验证。

## 12 华为田奇：盘古、端侧 AI 与具身智能

**记录：** 报告涉及盘古大模型、端侧 AI、时空记忆、长视频理解和具身智能。我把“环境 + 模型”理解为：模型在交互环境中行动、观察反馈并进入下一状态，能力需要在真实交互中体现。长视频越长、理解粒度越细，时间关系和 metadata 就越庞大；如何保留有用细节并控制处理成本，仍是难点。

**对 FrontPost 的联想：** 他们面对终端环境，我们可以关注信息环境里的真实反馈、长尾问题和复杂任务状态变化，逐步做好系统与环境的交互。

**一个小规模具身智能探索设想：** 我觉得 2 万元以内可以启动初步探索，目标放在复杂组合任务的泛化能力。围绕记忆、快慢思考协同，串起理解、推演、执行和反馈；同时看未见任务组合上的成功率、恢复能力、响应时间与成本。重点是让任务理解和执行效率一起变好。这是我的探索构想，不是报告公布的项目或预算。
