这次会议的报告涉及分子、医疗、视觉、端侧 AI 和具身智能等应用。整体来看，应用场景丰富，但神经网络和统计方法的细节讨论较少。技术落地仍要面对可靠性、真实反馈、长尾表现和成本等问题。下面按报告顺序记录要点，并补充我对网安 Agent 和 FrontPost 的联想；未听清或无法确认之处会单独说明。

## 总体感受

**记录：** 本次 Oral 报告以应用为主，神经网络和统计方法展开较少。研究选题可以同时评估效果和成本，例如考察减少上下文示例后，模型效果与调用成本如何变化。多篇报告也促使我思考：基准成绩高，并不必然意味着真实场景表现好。分数较高之后，更需要关注长尾任务、真实反馈和成本。

**记忆的价值：** 记忆可以减少重复查询、分析和重试，也能减少每次交互携带的上下文。它既可以服务单个 Agent，也可以沉淀为平台或团队经验。是否值得使用，仍要比较任务总成本与收益，不能只把记忆视为额外负担。

## 01 3D 与 TSA 做分子 AI for Science

**记录：** 报告用 3D 与 TSA 研究分子，但具体任务我没有记清。TSA（张量子空间分析）旨在尽量保留多维数据结构，并提取主要模式；SVD（奇异值分解）则从矩阵中提取主要方向。

**网安联想：** 可以把 Agent 的执行轨迹按“步骤 × 工具 × 行为特征”组织起来，观察提示注入前后的行为变化，或分析异常在多个 Agent 间的传播过程。

参考：[TSA 原论文](https://papers.nips.cc/paper_files/paper/2005/hash/332647f433a1c10fa2e2ae04abfdf83e-Abstract.html)、[SVD 说明](https://numpy.org/doc/stable/reference/generated/numpy.linalg.svd.html)。

## 02 医疗任务网络与 LLM

据现场记录，这项工作受武汉新冠临床场景启发，将专用网络与 LLM 结合，为临床判断和预警提供辅助。报告强调，医疗场景中的模型输出必须可解释，不能容忍幻觉，最终处置仍由人负责；报告还认为，模型迭代有望缓解幻觉。

**网安联想：** 可以由检测模型识别风险，再由 LLM 整合日志并说明依据，最终由人判断。

哈工深和港中文的相关工作，我没有完全听清，先记录方向。

**写作联想：** 论文说明局限时，可以明确指出额外信息或资源使比较不完全公平，也可以说明方法仅适用于某个细分场景。主动呈现最重要的局限，有助于读者判断结论的适用范围。这是写作体会，不代表相关报告存在这些问题。

## 04 AI + 化学与药物研发

标签稀疏时，优化已有候选有时比从零生成更实用。评分也可以拆成多个指标，衡量候选与理想目标的差距，再依据实验结果持续校准，而不只是拟合已有标签。

**🌰 网安多维奖励的例子：** 告警 Agent 可以从判断准确性、证据质量和调用成本三个维度评分。先把成本转换为成本效率得分（成本越低，得分越高），再将各维度归一化到 0–1，1 为理想值。以下是便于说明的简化示例，并非报告中的具体公式：R = α × 理想点奖励 + (1−α) × 最大差距奖励。这里把理想点奖励定义为三项得分的等权平均，把最大差距奖励定义为最低一项得分，并取 α = 0.4。A 的得分为 (0.90, 0.50, 0.90)，B 为 (0.75, 0.80, 0.75)，据此 A 约为 0.61，B 约为 0.76。B 的短板较少。越权等安全问题应设为硬约束，不能由其他维度的高分抵消。

相关思路可参照 [PRISM（2026 预印本）](https://arxiv.org/abs/2607.24353)中的理想点与 Chebyshev 多维奖励，以及[多目标参考点理论](https://pure.iiasa.ac.at/id/eprint/1117/7/WP-79-066.pdf)。PRISM 研究的是文生图提示词优化，并非药物研发；目前还不能确认它就是报告中提到的工作。

## 05 北京体育大学：老图像修复

报告提到，通道注意力可以提高有用特征通道的权重；交叉注意力则让一组信息按需读取另一组信息，例如在图像修复中结合文字指令。L2 像素误差可能把不同细节平均掉，导致结果模糊；如果用 L2 平滑梯度，也可能压平真实边缘。柯西型惩罚对大梯度的惩罚增长较慢，因此有机会保留边缘。现场提到的具体公式尚未确认。

参考：[PASD（ECCV 2024）](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/01705.pdf)、[TransRFIR](https://arxiv.org/abs/2404.10342)、[基于柯西型惩罚的 SAR 成像反演](https://arxiv.org/abs/2005.00657)。

## 06 视觉任务与长尾问题

长尾问题是指少数常见类别样本很多，而许多稀有类别样本很少。模型因此容易学好常见类，却漏掉稀有类。数据难收集、标注成本高都可能造成这一问题；简单复制少数类样本又容易过拟合。可尝试重采样、类别平衡或 focal loss、解耦分类器和 logit adjustment。网安评估还应关注各类召回率与宏平均 F1，不能只看总体准确率。

参考：[Class-Balanced Loss](https://openaccess.thecvf.com/content_CVPR_2019/html/Cui_Class-Balanced_Loss_Based_on_Effective_Number_of_Samples_CVPR_2019_paper.html)、[Focal Loss](https://openaccess.thecvf.com/content_iccv_2017/html/Lin_Focal_Loss_for_ICCV_2017_paper.html)、[Logit Adjustment](https://openreview.net/forum?id=37nvvqkCo5)。

## 07 下午场：端侧、边缘协同与具身智能安全

报告展示了端侧 LLM 与边缘节点的协同方式：端侧负责及时响应，周边节点提供更强的模型和任务调度。报告也提醒，具身智能的风险可能影响真实物理环境。对网安 Agent，可以考虑由轻量模型先筛查，再由强模型处理复杂分析，同时限制权限并保留停止机制。

## 08 多模态大模型、动态识别与蒙特卡洛树搜索

报告介绍了多模态动态识别、修复优化和评估体系，也提到 MCTS（蒙特卡洛树搜索）。MCTS 将多步决策展开为一棵树，通过反复选择、扩展、模拟和回传结果，把搜索预算集中到更有希望的路线。它可以在沙箱或模拟环境中评估 Agent 的候选动作，不需要修改模型权重。

**🌰 用 MCTS 规划网安告警调查的例子：** 对一条异常登录告警，Agent 可以选择查询登录历史、进程树或网络连接，并在日志副本中比较不同调查路线。如果异常进程与可疑外联相互印证，就优先沿这条证据链继续调查。搜索会增加调用成本，也依赖可靠的评价方式和可恢复的环境。

参考：[MCTS 综述](https://ieeexplore.ieee.org/document/6145622/)、[LATS（ICML 2024）](https://proceedings.mlr.press/v235/zhou24r.html)。

## 09 自适应动态规划

我记下的是自适应动态规划与贝尔曼最优原理。贝尔曼思路可以概括为：评估一个动作时，既要考虑眼前收益，也要考虑后续收益。ADP 则用数据近似价值或策略，再逐步改进。

**🌰 多 Agent 发言权分配的例子：** 在网安研判中，如果争议集中在 IP 情报，可以先让情报 Agent 补充证据；如果争议在于结论是否得到日志支持，则由复核 Agent 先发言。之后可根据新增证据、分歧变化和调用成本调整发言顺序。这是选题联想，具体算法是否需要考虑多轮影响，还要进一步判断。

参考：[Sutton 与 Barto《强化学习》](https://www.incompleteideas.net/book/bookdraft2018mar21.pdf)、[Bertsekas 的 ADP 讲义](https://arxiv.org/abs/1507.01026)。

## 10 华为相关产品负责人：Agent、GRPO 与记忆

报告提到，大模型正逐渐具备早期 Agent 中的任务编排和工具调用能力。GRPO 是一种强化学习方法：针对同一任务生成多条回答或轨迹，再依据组内相对奖励更新模型，不需要另行训练价值网络。不过，它仍依赖可靠的奖励，也需要多次采样。

**🌰 用 GRPO 训练网安 Agent 的例子：** 针对同一条沙箱告警生成四条调查轨迹；完成调查且证据充分的轨迹记为 1，其余记为 0，奖励依次为 (1, 1, 0, 0)。训练时依据组内相对奖励更新模型，使其更倾向生成成功且有证据的轨迹。GRPO 用于训练；MCTS 则在运行时搜索调查路线。

**记忆与长程学习：** 现场记下的 “mengen” 很可能是 MemGen；千问相关路线的论文名尚未确认。MemGen 根据推理状态触发并生成模型可用的隐空间记忆。这不同于把文字转成 embedding 后再检索原文，也需要模型内部接口和训练支持。显式文本记忆更容易查验；目前不能据此判断隐式记忆一定更节省算力。

SFT 可以学习经验证的任务轨迹，GRPO 可以比较同一任务的多条执行结果。RSI（递归自我改进）与 harness（由工具、上下文、记忆、调度、恢复和评估等组成的执行系统）可以形成“执行、验证、改进、再执行”的循环，但改进效果仍需通过真实任务验证。

记忆可以在 Agent、平台和团队等层级共享，以减少重复工作、降低总成本。生成式记忆与系统协同进化的调研已补入 Multi-Agent-Security-Analysis 开发周报，相关能力尚未实现。

参考：[DeepSeekMath / GRPO](https://arxiv.org/abs/2402.03300)、[MemGen](https://arxiv.org/abs/2509.24704)、[InfMem](https://arxiv.org/abs/2602.02704)。

## 11 潘云鹤院士：通专融合与可靠智能

我的理解是，医疗、具身智能等具体领域都需要可靠的智能系统，尤其要避免会影响决策或物理行动的高频幻觉。通专融合可以理解为将通用模型与专业知识、行业数据和实践经验结合起来。数据既要覆盖真实场景，也要包含足够细节；系统还需兼顾处理深度、覆盖范围和响应速度。报告从国家人工智能规划谈起，也把技术讨论与长期布局联系起来。

**FrontPost 联想：** 报告中的 proximity 让我想到“用户相对知识新颖性”：在内容可靠、且与用户当前问题相关的前提下，找到用户可能不熟悉、又有迁移价值的跨领域信息。报告中 proximity 的具体出处尚未确认。[Google 推荐文档中的向量接近度](https://developers.google.com/machine-learning/recommendation/overview/candidate-generation)和 [Google Similarity Distance](https://arxiv.org/abs/cs/0412098) 涉及相关概念，但不能据此认定它们就是报告所指。

**🌰 FrontPost 跨领域推荐的例子：** 关注网安 Agent 可靠性的用户，可以看到具身智能中的动作约束如何启发工具权限检查。系统还应说明两者的联系和迁移边界，避免只追求主题差异。可用 [MMR](https://doi.org/10.1145/290941.291025) 作为兼顾相关性与多样性的重排基线，再评估用户是否觉得推荐有启发。这个构想尚未在 FrontPost 实现或验证。

## 12 华为田奇：盘古、端侧 AI 与具身智能

**记录：** 报告涉及盘古大模型、端侧 AI、时空记忆、长视频理解和具身智能。我把“环境 + 模型”理解为：模型在环境中行动，根据反馈进入下一状态；模型能力也需要通过真实交互来评估。视频越长、理解粒度越细，时间关系和元数据就越复杂。如何保留有用细节并控制处理成本，仍是难点。

**对 FrontPost 的联想：** 他们面对的是终端环境；我们可以关注信息环境中的真实反馈、长尾问题和复杂任务状态变化，逐步提升系统与环境的交互能力。

**具身智能实验的起步门槛：** 他们分享的案例让我想到，具身智能实验的起步门槛未必很高。可以从投入相对有限的小规模实验开始，逐步探索任务理解、执行效率，以及复杂任务组合下的泛化能力。
