10 月 18 日听 CICAI 的报告，内容从分子、医疗、图像修复延伸到端侧计算和 Agent。自己的研究方向是网安 LLM Agent，听的时候也一直在想，其他领域的方法里有哪些可以借鉴。

下面按听报告的顺序整理，保留现场感受，再补上概念解释和自己的联想。没有记全的报告细节按当时印象保留；文中的网安例子是为了帮助理解，相关论文也有一部分来自会后的补充阅读。

## 总体感受

**记录：** 虽然是 AI 会议，目前听到的 Oral 感觉主要偏应用，对神经网络本身和统计学方法的展开较少。一些实在的选题可以有这层考虑：除了效果，也可以考虑成本，例如减少 context 中的示例后，效果如何变化，消融时把成本一起统计。

**畅想：** 我们做网安 LLM Agent，也可以关注“达到相近效果需要多少上下文、多少次调用、多少时间”。更少的信息和调用能否完成同样的任务，本身就有落地价值。

**评估的感受：** 多篇报告让人想到，评估基准的高分与实际效果未必一致；尤其分数刷到一定高度后，还应看真实任务覆盖、复杂场景表现和成本，不能只按排行榜判断系统是否更好。

**记忆的价值：** 记忆可以减少重复分析、查询和失败重试，也可以缩短每次需要携带的上下文，是降本增效的手段。它既可以服务单个 Agent，也可以沉淀为平台经验，进一步形成团队乃至集团级别可复用的经验；不同层级按权限共享。应看完成任务的总收益，不把记忆本身只当成负担。

## 01 3D 与 TSA 做分子 AI for Science

**记录：** 用 3D + TSA 研究分子，具体任务还没记清。TSA 是张量子空间分析，简单理解就是保留多维数据的结构，再提炼主要信息；SVD 是奇异值分解，从矩阵中提取主要模式。

**畅想：** Agent 的运行也可以按“步骤 × 工具 × 行为特征”组织，或许能提炼行为画像，看看提示注入前后的变化。多 Agent 的交互记录，也可以尝试从中寻找异常传播模式。

术语参考：[TSA 原论文](https://papers.nips.cc/paper_files/paper/2005/hash/332647f433a1c10fa2e2ae04abfdf83e-Abstract.html)、[SVD 说明](https://numpy.org/doc/stable/reference/generated/numpy.linalg.svd.html)。

## 02 医疗任务网络与 LLM

**记录：** 据称研究受到武汉新冠临床的启发。自己设计或组合网络，再结合 LLM。现场强调临床不能接受幻觉，也认为随着 LLM 迭代，幻觉有望缓解。系统负责辅助和警报，最终判断与处置由人负责；重点是简化人的工作，并提供可解释的结果。

**畅想：** 网安里也可以让检测模型发现风险，LLM 帮忙串联日志、解释告警，人做最后判断。一个有价值的方向是让分析人员少翻日志、更快理解风险，并能看到判断依据。

## 03 具身智能

**记录：** 哈工深、港中文相关的工作，具体内容没看明白，先记下方向。

**关于 limitation：** 可以大方承认，成绩高于 baseline，可能是因为引入了额外信息或资源，使比较存在不公平之处；也可以承认方法是在某个细分场景做文章，未必适用于所有情况。主动指出最严重的问题，把局限讲清楚，或许有“坦白从宽”的作用。这是对论文表述的感想，并非认定这项工作存在上述问题。

## 04 AI + 化学与药物研发

**记录：** AI + 化学用于加速化学药物研发，推动候选药物走向成熟和产出，探索分子比例、构型等。标签稀疏会限制大模型预训练；数据有限时，对已有候选做局部修补和迭代优化，可能比完全从零生成更实用。打分不一定依赖一个笼统的分数，也可以综合多项指标，衡量候选离理想目标还有多远，再用反馈奖励生成器、扩充优化信号。报告提到这类思路借鉴了 CV 等领域的经验，具体出处还需核对。

**畅想：** 网安 Agent 也可把成功率、误报、调用成本等拆开评价；奖励既看整体离目标多近，也照顾最差的关键指标。若能拿到分子实验或 Agent 任务的最终结果，就用最终结果反馈优化，反映真实效果，而不只拟合现有标签；中间打分器可辅助探索，最终仍要用真实结果校准，避免代理分数带偏生成器。

**🌰 多维 reward 的 Agent 案例：** 举例来说，网安告警研判 Agent 要根据告警和日志判断是否真实攻击、列出证据并给出处置建议。用同一批沙箱案例比较两版 Agent，把最终结果拆成三个独立 reward 维度：判断准确率、证据准确率、成本效率，并都归一化到 0–1。A 的三项分数是 `(0.90, 0.50, 0.90)`，B 是 `(0.75, 0.80, 0.75)`，理想目标为 `(1, 1, 1)`。等权时，分别算“整体差距奖励” `1 − 欧氏距离/√3` 和“最弱维度奖励” `1 − 最大差距`，再按 `α=0.5` 取平均：A 约 `0.60`，B 约 `0.76`。因此 B 的多维 reward 更高，因为它没有明显短板。若发生越权或危险操作，应设硬性淘汰条件，不能让其他维度的高分抵消。这是把多维 reward 迁移到 Agent 的示例，不是 PRISM 论文的实验。

**相关论文：** 目前找到最贴近这套“多维反馈 + 理想点距离 + 奖励生成器”描述的 CV 工作是 [PRISM（2026 预印本）](https://arxiv.org/abs/2607.24353)：它评估图像的语义一致性、美感和偏好，再用理想点与 Chebyshev 奖励迭代优化提示词。更早的理论脉络可看 [Wierzbicki（1980），多目标优化中的参考目标](https://pure.iiasa.ac.at/id/eprint/1117/7/WP-79-066.pdf)；多维而非单一评价分数的 CV 例子是 [CVPR 2024 的 MPS](https://openaccess.thecvf.com/content/CVPR2024/html/Zhang_Learning_Multi-Dimensional_Human_Preference_for_Text-to-Image_Generation_CVPR_2024_paper.html)。这些是相近方法和理论来源，不能据此断定就是现场报告引用的原文；PRISM 做的是文生图提示词优化，不是药物生成。

## 05 北京体育大学：老图像修复

**记录：** 北京体育大学的老图像修复工作，感觉与自己当前方向关联不大。提到了用通道注意力给不同特征通道加权，突出有用信息、压低无关响应。自己的感受是模型也可以“大道至简”，不一定越复杂越好。

**概念补充：** 通道注意力是在问“哪些特征值得多看”；交叉注意力是在问“一组特征该从另一组信息里取什么”。图像修复和条件生成中都能见到交叉注意力：PASD 用它把像素细节送入扩散模型，TransRFIR 用图像—文字交叉注意力按指令去除指定退化；2026 年的 X-Restormer++ 挑战赛方案仍采用重叠交叉注意力来处理图像局部空间关系。不同工作里交互的对象可以是图像与文字，也可以是两组图像特征。

**关于 L2 与柯西：** 像素 L2 loss 用平方误差衡量重建偏差，在细节有多种可能时容易得到平均化、偏模糊的结果；梯度 L2 平滑项则会重罚相邻像素的大变化，把真实边缘也压平。若现场说的是把梯度平滑项换成柯西型惩罚，常见形式如 `ρ(g)=log(1+(g/c)²)`：小变化仍平滑，大变化的惩罚增长较慢，从而少压制真实边缘。这里 `g` 可代表梯度，`c` 控制尺度；这是一般解释，具体“优化的柯西”指哪种公式或参数，仅凭现场记录还无法确定。柯西型惩罚也可能带来非凸优化和参数选择问题。

**相关工作：** [PASD（ECCV 2024）](https://www.ecva.net/papers/eccv_2024/papers_ECCV/papers/01705.pdf)、[TransRFIR（2024）](https://arxiv.org/abs/2404.10342)、[X-Restormer++（2026 挑战赛报告预印本）](https://arxiv.org/abs/2605.13258)；柯西型非凸正则的图像复原例子见 [SAR 图像复原论文](https://arxiv.org/abs/2005.00657)。

## 06 视觉任务与长尾问题

**记录：** 又一篇 CV 工作，具体方法没看明白；提到了长尾问题。

**概念补充：** 把类别按样本量从多到少排列，常见类别样本很多，后面大量类别样本很少，画出来像一条长尾。现实中的类别频率常不均衡，采集和标注也更容易覆盖常见类别；模型训练时因此更容易学好“头部”，漏掉稀有类别。它长期存在，因为少数类数据难收集、难标注，而且简单复制稀有样本容易过拟合。

**🌰 网安中的长尾问题例子：** 训练集里常见扫描攻击有十万条，几十种稀有攻击各只有十几条。模型可能把常见扫描学得很好、总体准确率很高，但对稀有攻击频繁漏报；这些样本少、种类多的攻击就是尾部类别。

**常见解法与启发：** 重采样或补充稀有类数据；用 class-balanced loss 调整类别权重，或用 focal loss 减少容易样本的主导作用；先学通用特征、再单独平衡分类器，或用 logit adjustment 校正类别偏置。不同方法有取舍，没有一个通吃方案。网安里对应少见攻击类型：除总体准确率外，还应看各类召回率和宏平均 F1，免得常见攻击的高分遮住稀有攻击的漏报。

**相关论文：** [Class-Balanced Loss（CVPR 2019）](https://openaccess.thecvf.com/content_CVPR_2019/html/Cui_Class-Balanced_Loss_Based_on_Effective_Number_of_Samples_CVPR_2019_paper.html)、[Focal Loss（ICCV 2017）](https://openaccess.thecvf.com/content_iccv_2017/html/Lin_Focal_Loss_for_ICCV_2017_paper.html)、[Decoupling Representation and Classifier（2020）](https://arxiv.org/abs/1910.09217)、[Long-Tail Learning via Logit Adjustment（ICLR 2021）](https://openreview.net/forum?id=37nvvqkCo5)。

## 07 下午场：端侧、边缘协同与具身智能安全

**现场感受：** 老教授讲课很松弛，拍手、抓握手势、耸肩、笑容自然，语调和音量有起伏，感觉很好。可以学习这种上台功夫：用手势强调概念、停顿留出思考时间，让身体动作和表达内容配合起来。

**记录：** 端侧和边缘计算中，简单方法也可能在具体任务上击败复杂方法，就像苍蝇脑子很小，也能完成适合自己的任务。报告提到已有可部署 LLM 的端侧硬件，附近的边缘节点还可以提供模型能力和任务调度。具身智能安全问题很多：报告从人类层面的极端风险，谈到像老鼠、蛇跑进家里一样让人不安的近身风险，强调安全的重要性。

**补充与畅想：** 端侧是设备自己处理，边缘是附近节点协助；可以让轻量模型先做实时判断，再把复杂任务交给更强的节点。选模型时可以同时考虑任务范围、延迟、能耗和可靠性。具身 Agent 的动作会直接影响物理世界，安全需要覆盖感知出错、指令被篡改、越权动作和失控后的停止机制。网安 LLM Agent 也可借鉴这种分工：小模型先筛查、本地保留敏感数据，复杂分析再调度给更强模型。

## 08 多模态大模型的动态识别、修复优化与评估体系

**记录：** 他们做的是一套围绕多模态大模型，把动态识别、多种方法的修复优化与评估结合起来的体系。报告还提到了蒙特卡洛树搜索。动态识别的具体对象、各模块如何衔接还没记清，下面的 MCTS 内容是补充理解。

**畅想：** 可以借鉴这种把识别、修复和评估串起来的思路：根据当前情况选择优化方法，再看结果是否确实改善。网安 Agent 也可以把发现问题、调整策略和验证效果接起来。

**概念补充：** 蒙特卡洛树搜索（MCTS）把“当前情况 → 下一步动作 → 后续结果”组织成树，通过反复抽样尝试，估计哪些动作更可能带来好结果。每轮通常做四件事：选择值得继续看的分支；扩展一个新动作；向后试走或估计结果；把结果沿路径传回，更新各分支的访问次数和价值估计。选择时既偏向表现好的路线，也会给探索不足的路线一些机会。

**为什么能用于 Agent：** 复杂任务通常要连续调用工具、观察结果、再作决策，每一步都会影响后面的选择，天然能展开成树。LLM 可以提出少量候选动作，MCTS 把有限的搜索预算更多投到有希望的路线，并在发现死路后返回其他分支。向后试走可以借助沙箱、模拟器或环境副本，也可用价值模型估计；实际结果越可靠，路线比较越有依据。这里的“回传”是更新搜索统计，本身不要求训练或修改 LLM 权重。

**🌰 用 MCTS 规划网安告警研判的例子：** 告警是“某账号出现异常登录”，Agent 下一步可查登录历史、进程树或网络连接。在日志副本或可恢复沙箱中，先沿几条路线试查：若查登录历史后只是发现用户出差，证据还不足；若查到异常进程，再关联到可疑外联，便更接近形成可验证的攻击证据链。搜索会据此给后一路线更多预算，同时保留其他可能。最后按预先定义的证据充分程度、结论正确性和调用成本评价路线，再选择实际下一步。

**启发与局限：** 适合存在多条行动路线、能验证结果的任务，尤其可以考虑网安调查和沙箱中的多步操作。代价是增加模型与工具调用；分支太多、评价器不准、环境无法恢复，都会影响效果。真实环境中的不可逆动作需要额外约束，不能为了搜索把每个分支都实际执行一遍。

**相关原文：** [MCTS 方法综述（2012）](https://ieeexplore.ieee.org/document/6145622/)、[Language Agent Tree Search，LATS（ICML 2024）](https://proceedings.mlr.press/v235/zhou24r.html)。LATS 是结合 LLM、树搜索与环境反馈的具体例子，不能据此认定就是现场报告的方法。

## 09 自适应动态规划

**记录：** 自适应动态规划，偏基础算法与控制理论，数学推导很多，涉及贝尔曼最优。

**概念补充：** 动态规划把一连串决策拆成“这一步怎么选，以及选完之后怎么办”。贝尔曼方程把两者接起来：一个动作的长期价值，等于眼前收益，加上折扣后的后续预期收益；要找最优策略，就比较各个动作的长期价值。自适应动态规划（ADP）则借助数据和函数近似（例如神经网络）估计价值或策略，逐步改进决策，帮助处理难以精确求解的问题。

**🌰 用贝尔曼思路选择 Agent 调查动作的例子：** 告警分析 Agent 可以直接给结论，也可以先花一次调用查询登录历史。查日志眼前增加成本，但可能为后续判断提供关键证据、减少反复查询；选择时就要把“现在花多少”和“后面能得到什么”合起来考虑。价值估计器根据过往任务结果学习哪些查询更值得做，策略再据此调整。

**与上一篇的联系：** MCTS 在决策时展开候选路线、试探后果；ADP 更侧重学习价值或策略来指导后续决策。二者可以结合：用学到的价值估计帮助搜索，更快判断哪些分支值得继续。

**自己的体会：** Agent 也能与传统算法结合。例如多 Agent 讨论时，可以把“下一轮谁获得发言权”作为决策问题，根据当前缺少什么信息、谁能提供新证据、发言成本和预期收益来选择。传统决策算法负责分配发言机会，Agent 负责生成内容和调用工具；更合理的调度本身也可能提升协作效果。

**🌰 多 Agent 发言权分配的例子：** 网安研判中有日志分析、威胁情报和复核三个 Agent。若争议是“可疑 IP 是否关联已知攻击活动”，先让威胁情报 Agent 补充证据；若争议是“已有结论是否被日志支持”，优先让复核 Agent 发言。再根据发言是否带来有效新证据、减少分歧以及调用成本，调整后续调度。这是自己的选题联想，具体适合规则、上下文老虎机、MCTS 还是 ADP，要看是否需要考虑多轮影响及能否获得可靠反馈。

**参考：** [Sutton 与 Barto《强化学习》](https://www.incompleteideas.net/book/bookdraft2018mar21.pdf)、[Bertsekas：最优控制与自适应动态规划中的价值迭代和策略迭代](https://arxiv.org/abs/1507.01026)。这些用于补充概念，不代表现场报告的具体方法。

## 10 华为相关产品负责人：模型能力内化与未来 Agent

**记录：** 报告谈到，大模型正在吸收早期 Agent 的一些能力，把任务编排、工具选择与调用等逐渐内化到模型中。这带来一个问题：当模型本身越来越能规划和使用工具，未来的 Agent 应该如何定义？

**自己的理解：** 可以从任务和环境来定义 Agent：围绕目标，在环境中采取行动、获取反馈并持续调整，以任务完成结果来评价的系统。随着规划和工具使用能力进入模型，Agent 系统的价值还可以体现在真实工具的执行、领域数据与记忆、权限管理、失败恢复、长期任务和多 Agent 协作上。网安方向也可以关注它能否可靠地完成调查、给出可验证证据，以及消耗多少时间和调用。

**GRPO 简介：** GRPO 是 Group Relative Policy Optimization，组相对策略优化，一种训练模型的强化学习方法。对同一个问题，让模型生成一组答案或行动轨迹，分别获得奖励，再比较各条轨迹相对本组平均水平的好坏，用这些相对优势更新模型，让表现更好的输出更容易出现。它由 DeepSeekMath（2024）提出，后来用于 DeepSeek-R1 的强化学习训练。

**🌰 用 GRPO 训练网安 Agent 的例子：** 对同一个沙箱告警任务，让同一个模型独立跑出四条调查轨迹；若两条找到了正确且有证据支持的结论，另外两条失败，可分别给奖励 `(1, 1, 0, 0)`。GRPO 利用组内相对奖励更新模型参数，鼓励前两类成功轨迹。这里是训练模型，运行时不一定每次都要生成四条路线。实际训练还会约束更新幅度，避免一次改得过猛。

**和前面内容的联系：** 多维 reward 决定“按什么标准打分”，GRPO 决定“怎样根据奖励更新模型”；MCTS 则侧重运行时搜索候选路线。GRPO 用组内比较替代额外的价值网络来估计基线，可节省这部分训练开销，但仍需要可靠的奖励和多次采样。如果组内奖励完全相同，基于相对奖励的这部分学习信号就会很弱或为零。

**原论文：** [DeepSeekMath（2024）](https://arxiv.org/abs/2402.03300)、[DeepSeek-R1（2025）](https://arxiv.org/abs/2501.12948)。

### 记忆、长程学习与系统协同进化

**记录：** 报告还谈到生成式记忆、可更新的隐式记忆，以及长程任务中模型与系统的协同进化。现场记下的“mengen”很可能是 MemGen；还提到了千问相关的循环记忆与 SFT 路线，具体论文名尚未确认。

**MemGen 是什么：** MemGen 有一个触发器判断当前是否需要记忆，再由记忆生成模块根据当前推理状态生成一小段隐空间表示，送回模型帮助后续推理。它可以训练记忆模块、保持主推理模型冻结；可借鉴的是“何时唤起经验、怎样组织当前需要的经验”。它需要模型内部状态与相应训练支持，接入方式不同于普通聊天 API 的文本记忆。

**隐空间与 embedding：** 隐空间可以理解为模型用一组数字表示信息的空间。文字里写“先查登录基线，再看异常进程”是显式记忆；模型也可能把与这些步骤有关的信息编码成向量。常见的 embedding 检索把记忆文本变成向量，用相似性找相关原文，更新时重算向量；MemGen 一类隐式记忆则生成可供模型直接使用的潜在表示。二者不能混为一谈，也不是给文本加上 embedding 就能自动学会经验。隐式表示可能更紧凑、可按当前状态组合，但不天然保证更省算力；显式文本则更容易查看、修正和追溯。

**🌰 从文本记忆到生成式记忆的网安例子：** 已有经验记录“某环境里运维脚本常触发 PowerShell 告警，判断时要核对签名、父进程和执行时段”。下次遇到类似任务，系统可以生成本轮需要的调查提示，把核对顺序带给 Agent，减少重复摸索。聊天 API 可以先用文本实现这种经验重构；真正的隐空间记忆还需要匹配模型内部接口。经验用来指导查询，本轮是否恶意仍由本轮证据验证。

**长程轨迹如何学习：** 一条轨迹包含任务拆解、工具调用、观察结果、记忆读写和最终结果。SFT 可以学习经过验证的优质轨迹或纠错示范；GRPO 则对同一任务生成多条轨迹，用任务结果的组内相对奖励训练策略或记忆模块。循环可以是“执行 → 验证 → 整理经验和训练数据 → 更新 → 再执行”；最终结果很晚才出现时，中间步骤的贡献归因、失败样本和纠错过程也很重要。已核实的相关例子 [InfMem](https://arxiv.org/abs/2602.02704) 在 Qwen 系列底座上采用 SFT 到 RL 的记忆控制训练，但不能据此认定就是现场提到的千问工作。

**RSI 与任务拆解：** RSI 是 Recursive Self-Improvement，递归自我改进。系统从执行结果中提出、验证并采用改进，再用改进后的系统继续产生经验。改进对象可以是记忆、Skill、任务拆解方式、调度规则、harness 或模型参数；任务拆解是其中可能被改进的能力。反复运行本身不等于改进成立，还要验证修改带来的实际收益。

**Harness 如何与模型协同进化：** Harness 是模型周边的执行系统，包括工具接口、任务循环、上下文和记忆管理、调度、失败恢复与评估。更好的 harness 可以帮助模型完成任务、产生更可靠的轨迹；这些轨迹又可用于训练模型。模型升级后，再调整原来的流程和分工，形成双向改进。衡量时既看任务成功与证据质量，也看重复调用、耗时和总成本。

**对自己系统的启发：** 可以沿单 Agent 经验、平台共享流程、团队/集团经验逐层组织记忆。结合现有的旁路观察和长记忆机制，先研究按任务阶段生成可复用指导，记录记忆是否减少重复劳动；有合适的可训练模型后，再研究隐式记忆。这些是后续值得尝试的优化方向。

**相关原文：** [MemGen](https://arxiv.org/abs/2509.24704)及[作者实现](https://github.com/bingreeky/MemGen)；[Recuris：递归演化工作记忆与经验记忆（预印本）](https://arxiv.org/abs/2608.24876)、[Recursive Harness Self-Improvement（预印本）](https://arxiv.org/abs/2607.15524)。这里列出的是补充阅读，帮助理解相关方向。

## 11 潘云鹤院士报告：通专融合与可靠智能

潘云鹤院士的报告，也回应了前面听报告时留下的一些问题。我的理解是，AI 进入医疗、具身智能等具体领域后，需要进一步走向可靠智能。尤其当模型的判断会影响真实决策和物理行动时，高频幻觉就很难被接受，可靠性必须成为能力建设的重要目标。

其中一个思路是“通专融合”：把通用大模型的能力与专业知识、行业数据和实践经验结合起来。例如在医疗领域，资深医生的专业经验和深入具体场景的数据，都可以成为重要支撑。数据仍然是关键基础，既要有覆盖真实场景的完整性，也要深入专业细节。落到应用，还要兼顾处理问题的深度、场景覆盖的广度与响应速度。

报告开篇回顾了此前国家层面的人工智能规划，并以今天的发展强调当年方向判断的正确性。这种开场也让我感受到一种学术与政策相衔接的视角：既讨论技术本身，也把技术发展放在国家长期布局中理解。与前面偏具体方法和应用的报告相比，这种观察问题的尺度很有特点。
